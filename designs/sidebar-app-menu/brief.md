# 应用入口收进左侧边栏 / 2026-10-11

任务：成员在任一会话或首页，都从同一个地方找到应用级功能（外观、名字、成员、通知、运行中、花费、项目权限、各类登录、扩展、重启、退出）。成功：每个应用功能只有一个可点击入口；会话菜单只剩会话自己的操作。

约束：

- H1 会话级操作（重命名、指令、压缩、新上下文、Fork、复制链接、归档、子 agent）留在会话的 ⋯ 菜单（作用对象是当前会话）。
- H2 ⌘K 启动器与 `/` 命令保留：键盘搜索通道，不算第二个可见入口。
- H3 手机上侧边栏是抽屉，入口须在抽屉里同样可达；折叠成 rail 时也要可达。
- H4 角色可见性不变：viewer 无 MCP sign-ins；Restart server 仅 owner 且受监管；单人模式 People 变为 Sign in another device。
- H5 Running 的实时计数不能丢（现在 foot tile 有数字）。
- S1 沿用现有 Tokyo Night/等宽字体/直角，不另造视觉。
