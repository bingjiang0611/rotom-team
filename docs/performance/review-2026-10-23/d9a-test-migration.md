The helper call sites in the default tests now use the explicit `seedHistoricalSession` name. The intermediate full-suite failures identified legacy execution-success assertions in tests that still called `say`, `submit`, schedules, forks, worktrees, spend, or extension task APIs. Those fixtures were subsequently migrated individually; the current full-suite result is recorded in the D9a validation report, not inferred from this mapping; this migration does not disguise those tests as native sessions. `appendHistoricalTurn` is available for read-model tests that need known input/assistant entries without dispatch.

The pinned artifact's extension source is copied only as data. Default tests never invoke the pinned app, read Git history, or load that source. Native execution/recovery/service-extension behavior remains covered by the existing `test/native-recovery.test.ts`, `test/native-service-extensions.test.ts`, `test/native-mirror.test.ts`, and `test/native-commands-proof.ts` fixtures; these D9a tests do not relabel archive sessions as native.
